# Adapters de IDE

Adapters são opcionais. O núcleo SAFRA não depende deles.

- `generic/`: instruções universais.
- `vscode/`: conveniências para VS Code.
- `antigravity/`: espaço para instruções específicas do Antigravity.

A lógica de agentes, skills, specs, regras e análise permanece fora dos adapters.
