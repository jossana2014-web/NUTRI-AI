# SAFRA-AI — ponto de entrada para agentes de IDE

Ao receber qualquer solicitação sobre cardápios:

1. Leia `AGENTS.md`.
2. Procure primeiro em `../Cardápios/`.
3. Use `agents/1 - orchestrator/AGENT.md` para decidir o fluxo.
4. Acione somente os agentes necessários.
5. Use `skills/`, `specs/`, `rules/`, `knowledge/` e `data/` quando aplicáveis.
6. Preserve os documentos originais.
7. Gere resultados derivados apenas em `output/`.
8. Para análises complexas, finalize com `auditor`.
