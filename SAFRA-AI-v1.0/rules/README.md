# Regras computáveis

As regras devem ser validadas antes do uso científico.

Cada regra deve conter:
- id;
- descrição;
- escopo;
- vigência;
- fonte;
- artigo/item;
- variável;
- operador;
- valor;
- periodicidade;
- comportamento quando faltarem dados.

Não inserir regra normativa com base apenas em memória do modelo.
