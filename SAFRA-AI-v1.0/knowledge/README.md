# Base de conhecimento

Inserir apenas fontes validadas e versionadas.

Sugestão:
- legislação oficial em texto/metadata;
- atos FNDE;
- normas CFN;
- documentos estaduais e municipais;
- referências nutricionais;
- calendário regional de sazonalidade;
- documentação sobre agricultura familiar.

Cada item deve registrar URL/fonte, data de acesso, vigência e versão.
